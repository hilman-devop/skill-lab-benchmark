# Skill Lab — Benchmark Dampak Skill AI

> Workspace untuk mengukur apakah skill benar-benar memperbaiki output model, dengan perbandingan bertekad dua kondisi oleh judge LLM.

## ✨ Fitur

- 11 skill diuji dengan dan tanpa skill
- 5 iterasi benchmark
- Output grading.json, timing.json, benchmark.json
- Laporan perbandingan berbasis HTML

## 🛠 Tech Stack

"Node --test" "Python" "JSON" "Markdown"

## 🚀 Menjalankan

```
node --test
python benchmark.py
```

## 📌 Catatan

Proyek ini merupakan bagian dari portofolio pribadi. Kode disusun untuk kebutuhan nyata,
bukan sekadar demo, sehingga sebagian konfigurasi spesifik lingkungan mungkin perlu
disesuaikan sebelum dijalankan.
